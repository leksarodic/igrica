# Asset Licenses

**Project:** *The Long Note* · **Build:** 0.1.2

The game is designed so that the repository can be cloned and rebuilt without downloading a single external asset. Everything shipped is generated by code in this repository, or is a platform resource used at runtime.

|---|---|---|
| Story, novella, dialogue, quests, lore, names | Written for this project | © 2026, all rights reserved |
| 3D meshes, terrain, props, characters, creatures | Generated at runtime by `scripts/art/mesh_builder.gd` and `mesh_factory.gd` | © 2026, all rights reserved |
| Materials, shaders, sky, water, grade | Written for this project (`assets/shaders/`, `scripts/world/region_base.gd`) | © 2026, all rights reserved |
| UI layout, icons, marks | Drawn or generated in code | © 2026, all rights reserved |

No sample libraries, stock music, texture packs, 3D model packs, fonts, icons, or generated images are included. No assets from Diablo, Minecraft, or any other game are used or imitated.

## Fonts

The UI requests system fonts by name. If a font is unavailable, Godot's default font is used. No font files are committed. If a future build ships custom fonts, they must be added here with the foundry, license, and modification note before merge.

## Music and sound

All audio is generated by additive/subtractive synthesis written in `audio_director.gd` at runtime. There are no recordings, loops, or sample packs. If curated recordings are added later, each file must be listed here with its source, license, and proof of permission. "Royalty-free" is not sufficient without the actual license text in the repository.

## Tools

The test suite uses only the Python standard library and Godot's built-in headless mode. No third-party Python packages, Node packages, Docker images, paid APIs, or external services are required to build or test the game.

## Reporting a licensing problem

If you believe an asset in this repository is not properly licensed, open an issue with the file path and the license concern. The asset will be removed or replaced before the next release.
